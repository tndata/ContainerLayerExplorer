Matrix: each column is a layer, and each row is a path. Click a cell to see the file, or a column header to see the layer.

Stack draws the image as layers, the first build step at the bottom and the last on top. Thin 0 B rows are steps that make no layer, such as ENV. The right side shows what is selected: the image ("What this image reveals", what anyone who has the image can read from its config and manifest), a layer (its details) or a step. Escape goes back to the image.

The page follows this image tag and updates by itself when you rebuild.

  • A added
  • M changed (whole file stored again)
  • D deleted (hidden by a whiteout marker)
  • ✓ in the Result column: the container gets this file
  • new after a rebuild, a layer whose content was not in the image shown before. A layer with the same content gets no badge, whether it came from the build cache or was built again. A reload clears the badges.
