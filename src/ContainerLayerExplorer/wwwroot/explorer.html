Each column is a layer, and each row is a path. Click a cell to see the file, or a column header to see the layer. The page follows this image tag and updates by itself when you rebuild.

  • A added
  • M changed (whole file stored again)
  • D deleted (hidden by a whiteout marker)
  • ✓ in the Result column: the container gets this file
  • new after a rebuild, a layer that was not in the build before (layers from the build cache get no badge)
